# Vue／Vite 审查与本地清理

审查依据：根目录 `AGENTS.md`、项目安装的 `vue` 和 `vite` skills，以及其响应式、库模式构建和 Rolldown 迁移参考资料。范围为静态数据加载、主要列表与推荐交互、Vite 配置和本地生成文件。

## 处理结果

| 问题 | 处理与效果 |
| --- | --- |
| 英雄名称缓存过期后刷新失败，内存中仍有名称就直接返回，后续调用不再更新 | 内存记录保存时间；保留旧名称供显示，后续调用可重试刷新，成功后更新保存时间。有效期内仍复用内存并合并并发请求 |
| Vite 在开发模式也固定注入 production 环境值 | 仅在生产构建时注入；开发环境由 Vite 保留 Vue 开发诊断，独立用户脚本仍获得静态 production 值 |
| 库构建使用 `rollupOptions` 兼容别名 | 改为 Vite 8 的 `rolldownOptions`，保留 IIFE 格式、导出设置和 es2018 目标 |
| 测试策略文档命令断行和字面量换行符影响阅读 | 修复 Markdown 表格与段落 |
| 根目录累积旧日志、临时数据和测试报告 | 清理 69 个生成目标，共 141 个文件、2,577,121 字节（约 2.46 MiB）；新增日志与 TypeScript 构建缓存忽略规则 |

现有搜索已在内存筛选，并将排序与输入分离；推荐详情已采用浅响应式；原始战绩页和推荐缓存已有数量限制。这些实现继续保留，不引入额外状态库或缓存框架。

## 清理范围

- 源码、样本、技能、AGENTS.md、依赖和当前构建产物保留。根目录不再残留 `.log` 或 `.review-tmp-*` 文件。
