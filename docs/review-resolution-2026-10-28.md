# 代码审查建议核查与处理

核查基线：v2.11.5，提交 `0aa4438`。工作区初始无未提交修改。本次核查使用当前代码、调用关系、离线测试和构建产物；没有调用真实账号接口。

## 逻辑与状态

| 建议 | 核查结论与处理 |
| --- | --- |
| 掌盟桥接引用未声明变量 | 成立。通用掌盟请求分支没有项目内发送方，已删除该分支，仅保留正在使用的详情 POST 请求及其响应协议。新增桥接端执行测试。 |
| 个人大区被浏览玩家的大区覆盖 | 成立。顶栏展示大区和个人常驻大区分开处理，仅主动选择才保存个人大区。“我的战绩”优先使用个人大区。相同大区下的一键返回本来已有实现，不能概括为全部失效。 |
| 未选择大区时默认跳转大区 1 | 函数中存在该默认值，但页面按钮在没有大区时被禁用，普通点击不会触发。仍将函数改为未选大区时直接返回，移除默认大区。 |
| 刷新和筛选重复清理共享缓存 | 成立。整页刷新由父组件清缓存一次，子组件只重新读取；切换本地筛选和卸载列表不清除共享原始页。已取消请求的迟到响应不写回缓存。 |
| 英雄名称异步更新与重复请求 | 成立。名称使用响应式引用，并复用正在进行的请求。加载失败可以重试，列表不再使用计数器强制重算。 |
| 验证码诊断状态非响应式 | 成立。改为响应式对象，使依赖它的界面可以随状态变化更新；此前错误对象变化也可能触发重新计算，因此不是每次诊断都会失效。 |
| 搜索历史不共享 | 两处独立读写与缺少数据结构校验成立。统一为共享响应式状态，读取旧存储键，写入统一存储键；过滤非法记录，保留最多十条，支持其他标签页同步。键名前缀不同本身不是功能错误。 |
| 装备槽重复 key | 成立。按固定槽位索引标识七个装备格，覆盖相同装备和多个空槽的更新测试。 |
| 技能图标异步覆盖 | 成立。每次监听失效或组件卸载后，旧请求不得回写图标和标题。切换图标时也重置头像后备状态。 |

## 性能与构建

| 建议 | 核查结论与处理 |
| --- | --- |
| 测试可缩短至约 3 秒 | 缺少足够证据。仅将确认无浏览器依赖的格式、胜负、段位和近期统计测试改为 Node 环境。保留组件测试的浏览器环境、样式支持及隔离，不改用共享环境。 |
| 静态图标地址前缀重复 | 成立。344 条符文和强化记录改存文件名，读取时恢复完整地址。符文同步脚本输出相同格式；逐项对比基线，地址、名称和其他元数据均不变。 |
| 强化表缺少自动同步 | 当前同步脚本确实只处理符文和装备。但现有材料没有提供可核验的强化表上游地址及响应结构，不能据此断言当前强化数据错误。本次保留强化条目，不新增未经验证的远程同步。 |
| 详情十行重复统计 | 成立。全场伤害最大值和各队击杀、伤害合计由父组件统一计算，排序与玩家行共用。单独使用玩家行时仍支持自行计算。 |
| 已被静态引用的模块再动态导入 | 成立。诊断数据改为静态导入，移除额外的异步包装。 |
| CI 重复检查且缺少网页构建 | 成立。统一构建命令执行一次类型检查，再生成脚本和网页；CI 在构建完成后执行全套测试，包含生成脚本验证。 |
